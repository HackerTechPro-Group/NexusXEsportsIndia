# Original NexusX Esports India Logo Asset Slot

Place your original high-resolution NexusX logo image in this directory named:

  `nexusx-logo.png`  (so the runtime URL is `./images/nexusx-logo.png`)

No replacement logo was auto-generated. Once `public/images/nexusx-logo.png` is present in this folder, the public navbar, footer, player login/registration portal, and admin dashboard automatically render your uploaded brand logo everywhere.
